**Алгоритм подсчёта листьев в бинарном дереве
Цель: определить количество узлов листьев (узлов без потомков) в бинарном дереве.
Основные понятия
•	Лист — узел, у которого оба потомка (left и right) равны null/None.
•	Внутренний узел — узел, имеющий хотя бы одного потомка.

Шаги алгоритма
Базовый случай: Если текущий узел None (пустое дерево) - возвращаем 0
Код:
if root is None:
    return 0

Проверка на лист: Если у узла нет левого и правого потомков - возвращаем 1
Код:
if root.left is None and root.right is None:
    return 1

Рекурсивный подсчет:
Рекурсивно считаем листья в левом поддереве
Рекурсивно считаем листья в правом поддереве
Суммирование: Возвращаем сумму листьев из левого и правого поддеревьев
Код:
left_leaves = count_leaves(root.left)
right_leaves = count_leaves(root.right)
return left_leaves + right_leaves

Визуализация на примере
Дерево:
       1
      / \
     2   3
    / \
   4   5

•	Узел 1: не лист (есть потомки 2 и 3) → считаем листья в поддеревьях.
•	Узел 2: не лист (есть потомки 4 и 5) → считаем листья в поддеревьях.
•	Узел 4: лист → возвращаем 1.
•	Узел 5: лист → возвращаем 1.
•	Узел 3: лист → возвращаем 1.
•	Итог:  листа.
Особенности реализации
•	База рекурсии: пустой узел (null) даёт 0 листьев.
•	Условие листа: оба потомка null.
•	Рекурсия: обрабатываем левое и правое поддеревья независимо и суммируем результаты.
•	Сложность:
o	Время: , где  — число узлов (каждый узел посещается один раз).
o	Память: , где  — высота дерева (глубина рекурсивных вызовов).



Временная сложность алгоритма подсчёта листьев в бинарном дереве O(n), где (n) количество узлов в дереве.
Алгоритм посещает каждый узел ровно один раз. Для каждого узла выполняются лишь элементарные операции (проверка на null, проверка наличия потомков), которые занимают константное время.
