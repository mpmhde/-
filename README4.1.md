Вариант 15. Локальный поиск для задачи о независимом множестве
Задача: реализовать локальный поиск для нахождения приближенного решения задачи о
независимом множестве.
Требования:
- Начать со случайного независимого множества
- Пытаться добавлять вершины, если они не смежны с текущим множеством
- Вывести найденное независимое множество и его размер
Входные данные:
Граф с 12 вершинами
Анализ ключевой строки алгоритма:

current_set.add(vertex)
1. Операция add() выполняется как при создании начального случайного множества, так и в процессе улучшения

В сочетании с random.shuffle(vertices) обеспечивает стохастичность разных запусков

2. Строка непосредственно выполняет основную операцию улучшения - добавление новой вершины
Перед добавлением проводится строгая проверка: if can_add: гарантирует, что вершина не смежна ни с одной вершиной текущего множества

3. Финальное состояние current_set становится результатом для вывода

current_set.add(vertex)  # Превращает возможность в реальное улучшение решения

Временная сложность алгоритма: O(n³)
Объяснение:

Алгоритм состоит из трех вложенных циклов:

Внешний цикл while - выполняется до O(n) раз в худшем случае (когда на каждой итерации добавляется по одной вершине)

Средний цикл for по вершинам - O(n) операций на каждой итерации внешнего цикла

Внутренний цикл проверки соседей - O(n) операций в худшем случае (когда вершина соединена со всеми остальными)

Вариант 15. Что такое локальный оптимум и почему метаэвристики нужны для его преодоления?
Локальный оптимум — это решение, которое является лучшим в своей ближайшей окрестности (среди соседних решений), но хуже глобального оптимума (наилучшего решения во всем пространстве поиска).
Обычные алгоритмы застревают - не могут ухудшить решение чтобы потом найти лучшее

Метаэвристики позволяют:

Временно ухудшать решение (имитация отжига)

Запоминать и избегать тупиков (табу-поиск)

Исследовать далекие области пространства (генетические алгоритмы)

Перезапускать поиск из новых точек
